### 1.1 Global Transport, Auth, Browser Storage & Cache Architecture

- **Supabase Client (`apps/web/src/services/supabase.ts`):** Singleton `createClient` configured with `auth.flowType = "pkce"`, `persistSession = true` (`localStorage` key `sb-<project-ref>-auth-token`), `autoRefreshToken = true`, and `detectSessionInUrl = false` (manual PKCE `?code=` exchange + implicit `#access_token=...&type=invite|recovery` bridge in `AuthProvider.tsx`).
- **TanStack Query Client (`apps/web/src/App.tsx:39-46`):** Global `staleTime = 30_000` (30s), `refetchOnWindowFocus = true`, `retry = 1` (most admin queries override `retry: false` for immediate fail-closed error reporting).
- **Zero Phantom Realtime (`apps/web/src/`):** React Web opens **zero** `supabase.channel(...)` or `.stream(...)` WebSocket subscriptions (`public.cancellations` is the only Realtime-published table in Postgres and is Student/Teacher operational data). Freshness relies strictly on TanStack Query mutation invalidation, window-focus refetch, 60s `EngineHealthBadge` polling, 1.5s active solver job polling, and explicit manual **Refresh** buttons.

### 2.2 Frozen Legacy Fallback (`lib/features/admin/**`, `web/`)

Per `AGENTS.md` §2, Flutter Web (`web/`) and `lib/features/admin/**` are **FROZEN** until Production Cutover (Environment B) and Phase 3B complete. Two contract anchors in `lib/features/admin/services/` remain reference baselines:

3. **Frozen Phase A Screens (`manage_courses_screen.dart`, `manage_batches_screen.dart`, `manage_rooms_screen.dart`, `manage_faculty_screen.dart`, `manage_course_eligibility_screen.dart`, `scheduling_workspace_screen.dart`):**
